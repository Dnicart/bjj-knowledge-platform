# Ground Game Guide

Educational Brazilian Jiu-Jitsu website for beginners. The Angular application lives in the [`client/`](client/) directory.

## Quick start

```bash
cd client
npm install
npm start
```

Open [http://localhost:4200](http://localhost:4200).

## Build & SSR

```bash
cd client
npm run build
npm run serve:ssr:client
```

## Stack

- Angular 22, TypeScript, SCSS
- Standalone components, Signals, Angular Router
- SSR with prerendering via `@angular/ssr`

See [client/README.md](client/README.md) for full project documentation.
